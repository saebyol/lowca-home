# 로우카 홈페이지 올리기 · 연결 순서

## 폴더 구성
- `site/` — 실제로 올리는 홈페이지 폴더예요. 이 폴더를 통째로 올리면 돼요
  - `index.html` 메인 / `jeumeu/` `sinami/` `yunseul/` `haseulla/` 방 페이지 / `facilities/` 공용 공간 / `faq/` 자주 묻는 질문
  - `config.js` 구글 시트 주소, 카카오톡 주소 같은 설정이 모여 있는 파일 (이 파일 하나만 고치면 모든 페이지에 반영돼요)
  - `images/` 사진, `sitemap.xml` `robots.txt` 네이버 검색용 파일

## 1. 무료로 올리기 (깃허브 + Cloudflare Pages)
1. github.com에 가입하고 빈 저장소(예: `lowca-home`)를 만들어요 (README 등 아무 파일도 추가하지 않기)
2. Claude가 이 폴더 전체를 저장소에 올려요
3. dash.cloudflare.com 가입 → **Workers & Pages → 만들기 → Pages → Git에 연결** → 저장소 선택
   - 프레임워크 프리셋: 없음 / 빌드 명령: 비워 두기 / **빌드 출력 디렉터리: `site`**
4. 배포가 끝나면 `프로젝트이름.pages.dev` 주소가 생겨요
5. 이후에는 저장소가 바뀔 때마다 1~2분 안에 홈페이지에 자동으로 반영돼요

※ 내 주소(lowca.kr 같은)를 쓰려면 Cloudflare Pages의 **사용자 지정 도메인**에서 연결해요
※ 주소가 정해지면 `build/build.py`의 `SITE_URL`을 바꾸고 다시 빌드해요 (Claude에게 맡기셔도 돼요)

## 2. 구글 시트 연결 (입주 가능일 달력)
1. 매출 장부 구글 시트에서 **확장 프로그램 → Apps Script**를 열어요
2. 기본 코드를 지우고 `apps-script.gs` 내용을 붙여 넣은 뒤 저장해요
3. 함수 선택 칸에서 `연결확인`을 고르고 **실행** → 본인 계정으로 권한을 허용해요
   (경고 화면이 나오면 '고급 → 안전하지 않음으로 이동'을 누르면 돼요 본인이 만든 스크립트라서 뜨는 안내예요)
4. **배포 → 새 배포 → 유형: 웹 앱**, 실행: **나**, 액세스: **모든 사용자**로 배포해요
5. 나온 `https://script.google.com/macros/s/.../exec` 주소를 `site/config.js`의 `API_URL: ""` 따옴표 안에 넣어요

※ 이름·연락처·금액 칸은 홈페이지로 나가지 않아요 스크립트는 입주일·퇴거일·방이름 세 칸만 읽어요
※ 카카오톡 채널 채팅 주소가 생기면 `config.js`의 `KAKAO_URL`을 바꿔 주세요

## 3. 네이버 검색 등록
1. searchadvisor.naver.com → 웹마스터 도구 → 사이트 등록에 홈페이지 주소를 넣어요
2. 소유 확인은 **HTML 태그**를 고르고, 나온 `<meta name="naver-site-verification" ...>`를 `site/index.html`의 안내 주석 바로 아래에 붙여 넣어요
3. **요청 → 사이트맵 제출**에 `sitemap.xml` 주소를, **웹 페이지 수집**에 각 페이지 주소를 넣어요
4. 네이버 플레이스(스마트플레이스)의 **홈페이지** 칸에 새 주소를 연결해요
5. 블로그 글에도 홈페이지 링크를 걸어 두면 좋아요

## 4. 네이버 지도 넣기 (선택)
네이버 클라우드 플랫폼(ncloud.com) → Maps → Application 등록(Dynamic Map, Geocoding)
→ Web 서비스 URL에 홈페이지 주소 → 발급된 Client ID를 `config.js`의 `NAVER_MAP_KEY`에 넣어요

## 고칠 때 참고 (Claude용)
`build/` 폴더가 원본이에요 `src.html`, `faq.json`, `photos.json`을 고친 뒤
`python3 build/build.py && python3 build/prerender.py`를 실행하면 `site/`가 새로 만들어져요
